# PedeIA — Versão mestra das solicitações

Esta pasta foi preparada a partir do ZIP-base mais recente disponível no histórico do projeto e contém:

- o código-base real da versão mais recente;
- `ALTERACOES-COMPLETAS.md`, com todas as solicitações recuperadas;
- `SUPABASE-MASTER-ALTERACOES.sql`, com uma migração incremental consolidada para os recursos de banco que podem ser preparados sem apagar dados.

## Importante
Esta não é uma alegação de que cada item da lista já está implementado. A auditoria encontrou recursos que já estão no código e outros que ainda precisam de implementação, principalmente Promoções avançadas, Relatórios, Localizar entregador/mapa administrativo e parte da otimização ORS.

A finalidade desta versão é estabelecer uma base única e verificável para a próxima implementação, evitando que alterações sejam perdidas entre ZIPs.
